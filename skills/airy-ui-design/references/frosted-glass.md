# Lumi 磨砂玻璃材质

## 五层关系

1. **底色**：暖瓷白或极浅冷灰，避免满屏彩色渐变。玻璃后面留很淡的浅鼠尾草绿色差，形成可透射的层次；不叠加粉杏和其他色系。
2. **磨砂内层**：乳白半透明，背后的色与轮廓被柔化，文字位于其上保持锐利。磨砂是漫透射，不是简单降低整个组件透明度。
3. **边缘**：细白亮边配极淡冷灰外沿；圆形重点控件可增加一圈细腻透镜边，不能所有容器都用粗环。
4. **光与阴影**：上左方统一柔光，宽而浅的落影与更小的接触阴影表明悬浮高度。一个页面的光向必须一致。
5. **内容**：深石墨正文、简洁线条图标；浅色用于背景与材质，不能牺牲文字和行动的对比。

主输入框略微透光，小型发送控件更精细；列表、表单正文和长内容采用更稳定的底色。不要同时叠加高透明、强折射、强模糊和高饱和背景。最新构图参考优先于早期材质参考：精细玻璃不能成为放大功能卡、圆形徽章与阴影的理由。

## 网页 CSS 起点

根据页面实际背景验证效果与性能后调整。背景模糊只有在背后存在色差时才可见；下例默认提供不透明降级。

```css
.lumi-glass {
  background: #f4f6ef;
  border: 1px solid rgba(255, 255, 255, .88);
  border-radius: 28px;
  color: #294a40;
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, .9),
    inset 0 -1px 1px rgba(75, 98, 79, .05),
    0 2px 5px rgba(47, 66, 50, .025),
    0 20px 48px rgba(47, 66, 50, .06);
}
@supports ((backdrop-filter: blur(24px)) or (-webkit-backdrop-filter: blur(24px))) {
  .lumi-glass {
    background: rgba(255, 255, 255, .68);
    -webkit-backdrop-filter: blur(24px) saturate(110%);
    backdrop-filter: blur(24px) saturate(110%);
  }
}
```

不要对包含文字的整个组件设置 `opacity` 或 `filter: blur()`。不用多层全屏背景模糊；优先在少数关键入口使用，低性能设备可降级为稳定浅色表面。悬停只轻调亮度或阴影，不制造大范围跳动。

## 设计图要求

- 原创构图，Lumi 品牌，暖瓷白摄影棚氛围，柔和大面光；体现材质而非堆叠装饰。
- 一个重点视觉：居中短标题与单个悬浮磨砂输入框；下方一句短说明，四周留足空间。模式选择收在输入框内，不增加两张大入口卡、大玻璃球或额外总按钮。
- 横向画面中内容组约 45–60% 宽；标题离框约 56–80px，框与下方说明约 32–48px 起。上下留白约各 20% 起，按内容和窗口调整；正文不因宣发式留白被裁切。
- 磨砂、厚度、细边、透光、接触阴影都应可辨。色彩局限在玻璃后方与边缘附近，不把整张图染绿；暖瓷白仍占大多数面积。
- 只用主标题、正文、辅助三档字号，中文锐利可读，不在光晕里放淡字。
- 以手机产品宣发的精细度作为工艺参考，不加入苹果标志、设备模板和仿制宣传文案。
- 位图可有真实玻璃微折射；实际网页保留克制的材质提示，不强制依赖复杂 3D 渲染。
- Lumi 首屏保留三张紧密重叠的小型引导插片，整组固定在输入框左上边缘后方；浅鼠尾草绿磨砂发送钮保持约 44–48px。卡片与按钮使用同一乳白浅鼠尾草绿材质，不分别染色。标题采用清雅展示字体，控件使用清楚的无衬线，暖瓷白留白仍是主体。
