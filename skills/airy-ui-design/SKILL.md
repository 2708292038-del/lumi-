# 精致磨砂玻璃界面设计

让用户先看到重点，再理解内容，最后自然行动。用产品宣发设计的空间感与精细材质表现建立高级感：中性底色、乳白磨砂、局部透光、薄而精致的玻璃边缘。用户指定的品牌、文案和既有组件规范优先于这里的默认值。

## 专属风格方向

当前版式基准：居中短标题 → 一个悬浮磨砂输入框 → 一句轻说明。以最新参考图的大幅留白和单一视觉中心为准，默认不使用左右分栏、两张大功能卡或多个同等主行动。先建立安静的空间，再打磨玻璃。

Lumi 首页三个引导预览卡紧密重叠，从输入框左上边缘后方露出，作为小巧的引导入口；发送按钮使用浅蓝紫粉透光的小磨砂圆钮。预览仅显示短标题，完整三页通过打开引导阅读，不能把长文案缩成微小字塞进插片。

参考用户提供的磨砂圆形控件，提炼柔光、半透明、浅彩透射和悬浮厚度，重新设计适合当前产品的构图与组件。苹果手机宣发的灵感落实为空间节奏、精密表面和清楚排版，不复制苹果品牌、设备外观或具体宣传页面。

借鉴 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 的玻璃材质分类，以及 [Frontend Design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 的视觉方向与主视觉克制原则。本文件按用户偏好独立编写，不复制上游正文，不依赖上游脚本或安装包。

## 开始设计

- 先读现有页面、设计变量、组件和相关说明；改版时保留可用的交互和设计系统，避免另造一套组件。
- 说明本屏的核心问题与主要行动。减少并列任务，用渐进展开承载次要信息；低密度不能靠隐藏必要功能或缩小文字实现。
- 阅读参考图时提炼空间比例、视觉重心、材质和色彩关系，不复制构图、图标、品牌或具体卡片。参考图中的低对比文字不应成为规则。
- 在实现前明确桌面与移动端的阅读顺序、标题换行和主要行动位置。没有参考图时说明依据来自用户描述。

## 视觉原则

1. **空间先于装饰。** 一屏一个明确焦点。内容以标题、短正文、必要视觉、行动组成；相关内容靠近，区块间留白明显大于区块内间距。
   宣发首屏的内容组约占画面中部 45–60% 宽度；上下均留整块空白。标题与输入框、输入框与说明之间保持清楚的节奏，不用把组件放大填满空间。
2. **容器有目的。** 卡片用于可选择入口、独立对象或边界明确的任务，普通说明直接排版。避免卡片套卡片和满屏等权卡片。
3. **浅彩透过材质。** 珍珠白或极浅灰为主，蓝紫、粉杏中按需要选一至两组。让色彩从玻璃后方被柔化后透出，局部有光，大片区域安静；文字区域保持稳定明度。
4. **玻璃有细节。** 乳白磨砂内层、薄白亮边、轻微内阴影、柔软落影共同描述材质。主要用于单个悬浮输入框与小型控件，背景承载淡淡柔光。透镜厚度轻到不压过正文；避免塑料质感、镜面强反射、粗发光边框、硬浮雕和大圆形装饰徽章。
5. **重点靠位置与对比。** 主标题最清楚，正文足够深，次要信息安静但可读。每屏只强调关键一句；避免大量粗体、随机大字和装饰性英文大标题。
6. **交互轻但明确。** 主行动有稳定可见的底色与文字对比。悬停、按下、焦点、禁用、加载和错误状态均能区分，不仅靠颜色表达状态。

## 默认设计变量

以这些值作为起点，结合既有系统调整，不必机械套用。

| 类型 | 默认值 |
| --- | --- |
| 背景 / 表面 | 珍珠白 `#F7F8FA`；玻璃背景为白色 60–78% 不透明度，按背景与对比调整 |
| 主文字 / 正文 / 辅助 | `#252B3A` / `#535C70` / `#687286` |
| 主行动 | Lumi 发送按钮为乳白蓝紫粉透光圆钮配深蓝紫箭头；其他行动可用石墨色 `#303642` 配白字，实际渲染后校验对比 |
| 浅彩 | 蓝 `#E5EFFC`、紫 `#ECE7FA`、粉 `#F8E8F0`，按需选用 |
| 间距 | 8、16、24、32、48、64、96px；移动端外边距 24px 起 |
| 圆角 | 输入与按钮 14–18px，入口 20–24px，主要展示面板 28–32px |
| 玻璃模糊 / 边线 | 背景模糊 20–32px 起；1px 半透明白边与极淡冷灰外沿，按实际尺寸调整 |
| 阴影 / 高光 | 上左柔光；低透明度宽落影、轻接触阴影、一条内侧亮边，避免黑色硬边 |
| 内容宽度 | 文本区约 560–680px；双入口区约 760–880px，避免无限拉宽 |

### 字体与密度

- onboarding 只用三档字号：主标题桌面 48px / 移动 32px；正文与按钮桌面 18px / 移动 16px；辅助信息 14px。三个页面保持相同字号、字重和槽位。
- 宣发主标题采用清雅的现代宋体或有细微笔画变化的展示字体，正文与控件保持易读的无衬线；最多两个字体家族。先验证实际字体的中文字符与标点，避免书法体、过粗宋体和随意拉大字距。主标题只是内容组的一部分，不占据半屏。
- 主标题 medium / semibold，中文行高约 1.25–1.35；正文行高约 1.65。不要缩字解决内容溢出，先删减重复、调整换行或让页面滚动。
- 标题最多两行，正文目标两至三行；在最窄设备上允许自然换行，不裁切文字。
- 首屏避免同时堆叠功能网格、指标、长说明和多组行动。一般保留一处核心视觉和一组行动；第三页两个互斥入口可以同时作为行动。

## 实现与交付验证

- 按目标技术栈实现，复用组件与变量；设计效果图与可运行页面分别标明。生成的位图是视觉方向参考，不等同于完成产品实现。
- 检查桌面约 1440px、移动 390px 与窄屏 320px；阅读顺序一致，入口在移动端纵向排列，正文不溢出，按钮不因固定底栏或键盘被遮挡。
- 必要时允许滚动；不得用固定高度裁切标题、提示或行动。触控目标建议至少 44px；支持键盘、可见焦点和减少动态效果偏好。
- 实际文字对比至少达到普通文字 4.5:1、大字 3:1；可操作边界与焦点保持可辨识。不要把淡色背景值直接当文字颜色。
- 动效约 160–240ms，轻淡入或短位移；不使用持续漂浮光晕和自动轮播。反馈文案说明下一步，不用装饰填补空白。
- 交付前逐屏检查：五秒内能说出重点吗？主行动明显吗？文字足够少且可读吗？三页槽位一致吗？光晕是否干扰阅读？第二页是否明确“由用户选择方法后沿其逻辑推演”？
- 验证玻璃不是一块普通白卡：背后存在可被模糊的浅色差异，边缘可辨，落影说明高度，文字不被折射扭曲；关闭模糊后使用稳定的不透明浅色表面。
